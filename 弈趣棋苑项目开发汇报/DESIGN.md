## 1. 画布与全局母版

### 三维划分（三区母版）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | `0–120px` | 120px（上 padding 20px） | 主标题 34px bold，左对齐；**右侧不得放任何装饰小图**；下方 2px 朱砂短横线（宽 56px）作视觉分隔 |
| **B · 内容区** | `120–660px` | 540px | 一切正文、图表、配图、卡片；禁止挤占 A / C 区 |
| **C · 页脚条** | `660–720px` | 60px（下 padding 20px） | 左侧「弈趣棋苑 · 项目开发汇报」14px 灰字；右侧页码 `NN / 64`，14px；两者同色同字号 |
| 页面 padding | 左右 `72px`、上下 `20px` | — | 内容实际可用宽 = 1280 − 72×2 = **1136px** |

- 封面 / 章节扉页 / 结束页：可省略 C 区、采用自定义版式。
- 其余内容页：A / B / C 三区严格一致，**逐页复用**。
- **L3 角标**（朱砂方印）位置固定：C 区左侧、项目名前 24px 处，尺寸 26×26px；扉页与封面放大到 44×44px 置于右下角。

### 高度分配基线（内容页）
```
上 padding 20 + A 区 120 + B 区 540 + C 区 60 = 740 > 720
```
→ 实际执行：`padding: '20px 72px'`（上下各 20），A 区实高 **96px**、B 区实高 **516px**、C 区实高 **48px**，合计 20+96+516+48+20 = **700px ≤ 720px** ✅（余 20px 作为弹性余量）

## 2. 颜色系统

### 色彩池（4 hex，其余一律用 rgba 派生）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **纸色**（背景 / 中性） | `#F5E3BE` | 页面底色、浅色卡片底、正文反白时的底 |
| **墨色**（文本 / 中性） | `#2A2118` | 标题、正文、页码、边框 |
| **主色 · 木棕** | `#8C5A2B` | 标题栏色块、巨型数字、图表主系列、卡片描边 |
| **强调 · 朱砂** | `#B3271E` | 只出现在焦点元素：章节序号、关键数字、CTA、印章、分隔短线 |

### rgba 派生规则（不新增 hex）
| 用途 | 值 |
| :--- | :--- |
| 浅卡片底 | `rgba(140,90,43,0.08)` |
| 深色页面底 | `rgba(42,33,24,0.92)` |
| 主色描边（弱） | `rgba(140,90,43,0.28)` |
| 正文次级色 | `rgba(42,33,24,0.66)` |
| 反白正文（深底上） | `rgba(245,227,190,0.86)` |
| 章节号底纹 | `rgba(179,39,30,0.10)` |

### 色彩面积分配

| 色彩角色 | 常规页占比 | 说明 |
| :--- | :--- | :--- |
| 纸色（主色位） | ≤ 60% | 页面背景、大色块 |
| 木棕（辅色位） | ≤ 30% | 标题栏、卡片底、左侧色块 |
| 朱砂（强调） | **≤ 5%（supporting）/ 15–20%（hero）** | 巨型数字、章节序号、印章 |
| 墨色（中性） | 剩余 | 文本、页脚、边框 |

**节奏要求**：P04 / P11 / P18 三页为 hero，朱砂占比提到 15–20%，与常规页形成显著差异 ✅

### 渐变与半透明
- **章节扉页底**：`linear-gradient(160deg, #2A2118 0%, #3E2E1E 55%, #8C5A2B 100%)` + `wood_panel.png` 以 `opacity: 0.22` 叠加（`overlay`）
- **封面 / 结束页底**：`wood_dark.png` 全幅 `objectFit: cover`，上叠 `linear-gradient(90deg, rgba(42,33,24,0.94) 0%, rgba(42,33,24,0.62) 52%, rgba(42,33,24,0.20) 100%)`
- **卡片**：`background: rgba(140,90,43,0.08)` + `border: 1px solid rgba(140,90,43,0.28)` + `borderRadius: 10`（**无阴影**——本项目视觉主张是"克制、无塑料感"，禁用通用法则里的 `boxShadow` 浮起感）
- **木棕实底卡片**：`linear-gradient(135deg, #8C5A2B 0%, #6E4520 100%)`，字用 `#F5E3BE`

### 通用禁忌（已内化为本项目铁律）
- 禁止同一页面出现 ≥2 套主色板
- 禁止高饱和撞色铺满 ≥1/3 页面
- **禁止 boxShadow 浮起效果**（与项目"拒绝塑料感"主张冲突）
- 禁止每页色彩比例雷同

| 脚注 / 页码 | 14 | regular | 1.4 | C 区 |

### 字体个性策略

| 角色 | 字体族 | 说明 |
| :--- | :--- | :--- |
| **标题 / 巨型数字** | `'Songti SC', 'STSong', 'SimSun', serif` | 宋体系——衬线、有书写骨力，呼应传统棋苑气质；数字用同一族的 bold |
| **正文 / 表格 / 页脚** | `'PingFang SC', 'Microsoft YaHei', sans-serif` | 无衬线——小字清晰、屏幕可读 |

- **仅 2 套字体家族** ✅（衬线标题族 + 无衬线正文族）
- **巨型数字必须与正文不同字重/字体**：数字用宋体 bold，正文用黑体 regular ✅
- 禁止所有页面只用系统默认无衬线 ✅

## 4. 信息密度门禁

| 页面类型 | 最少元素数 | 正文字数下限 | 图片/图表数下限 | 主视觉占内容区 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 3 | 20（实际约 60） | 1 | B 区 ≥ 35% ✅ |
| 目录 | 7 条目 + 引导句 | 80（实际约 140） | 0 | — |
| 内容页 · 单主题 | 3 | 180（实际 200–320） | 1 | B 区 ≥ 30% ✅ |
| 数据页 | 3 | 80（实际 180–190） | 0（用巨型数字作主视觉） | 锚点数字 ≥ 72px ✅ |
| 章节扉页 | 3 | 30（实际约 40） | 1 | B 区 ≥ 40% ✅ |
| 结束页 | 2 | 20（实际约 30） | 1 | — |

- **留白上限**：常规内容页 ≤ 35%（实际 15–25%）；
- **焦点留白**：每个巨型数字 / 主图周围 ≥ 40px 呼吸空间；
- **容器填充率 ≥ 85%**：卡片正文块与尾部引文条用 `justifyContent: 'space-between'` 或 `marginTop: 'auto'` 钉底；
- **横向兄弟卡对齐**：同类卡片的三段（标题 / 正文 / 尾条）在 y 轴等高对齐。

## 7. 生成自检清单（每页提交前逐项确认）

1. 母版三区齐全（A 96px / B 516px / C 48px），C 区含 `NN / 64`
2. A 区右侧无装饰小图，全篇标题位置一致
3. L1 主视觉占 B 区 ≥ 30%，未用 L3 顶替
4. 仅用 4 个 hex（`#F5E3BE` / `#2A2118` / `#8C5A2B` / `#B3271E`）+ rgba 派生
5. 仅用 2 套字体家族
6. 与上一页版式不同；留白 ≤ 35%（hero / 扉页 / 封面除外）
7. 有 ≥1 个视觉锚点（≥44px 元素 或 ≥40% B 区面积的图）
8. 与上一页视觉重量差异 > 1.5:1 或结构明显不同
9. 色彩分配符合本表；朱砂只出现在焦点元素
10. role 与 STORY.md 一致；hero 页有 ≥48px 锚点数字或 ≥40% 主视觉
